# Wizard’s Trial

**Live Demo:** https://sreeashish.github.io/Wizards_Trial/

**Wizard’s Trial** is a fast prototype WebGL game built in Unity in a single day to showcase rapid prototyping and core gameplay implementation skills.

---

## 🧙 About

Wizard’s Trial is a first-person magical duel experience where the player wields a staff to cast runic projectiles against an enemy wizard. The enemy wizard attacks using fiery magic, creating dynamic spell combat encounters. This prototype was developed from scratch in under 24 hours to test rapid development workflows in Unity and WebGL deployment.

You can play the live demo in your browser using the link above.

---

## 🎮 Features

- First-person movement and camera controls
- Staff-based spell casting with runic projectiles
- AI opponent with fire magic attacks
- WebGL deployment for browser play
- Rapid prototype focused on combat feel and responsiveness

---

## 🛠 Built With

- **Unity** — core development engine  
- **C#** — gameplay programming  
- **WebGL** — platform build target  
- Custom scripts for projectile behavior, enemy AI, and player control
